MY GYM COACH — INSTALLABLE PWA

This package preserves the 12-week plan, embedded exercise illustrations, mobility routines, and workout history logging from the original HTML app.

IMPORTANT: A PWA must be served over HTTPS (or localhost). Opening index.html from My Files / content:// does NOT install it. This package has not been deployed online.

EASIEST HOSTING OPTION (GitHub Pages, public hosting):
1. Create a new GitHub repository, upload the CONTENTS of this folder (index.html, sw.js, manifest.webmanifest, icons/).
2. In Settings > Pages, choose Deploy from a branch, main, root; save.
3. Wait for the HTTPS URL, then open that URL on your Samsung phone in Chrome.
4. Chrome menu > Add to Home screen > Install. Open once online to cache offline assets.

PRIVACY: The app's source code, exercise plan, and embedded pictures will be publicly accessible if hosted on public GitHub Pages. Your workout entries are saved only in the browser's local storage and are NOT uploaded to the host. However, hosting services may collect ordinary access logs. For a private deployment, use a private hosting arrangement instead.

DATA MIGRATION: Before switching from the old HTML file, open its History tab and export JSON backup. After installing this PWA, open History > Restore backup and select that JSON file. Local storage is origin-specific; it does NOT transfer automatically.

BACKUPS: Export JSON regularly. Uninstalling or clearing browser data may erase saved workouts. This is not a cloud-synced app.
